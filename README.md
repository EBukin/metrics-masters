# metrics-masters

The objective of this project is to reproduce the seminal methodlogies often used by me in the impact evaluaiton.
Intiail ambition is to create a clear taxonomy and structure of methods and then implement them with the examplary data sets in R, an possible other software such as Stata.

Proposed structure is:

- Difference in Difference (DiD)

  - Cohort-level DiD
  - Staggared + Heterogenous treatment effects
  - Continuous DiD

- Panel Regression

  - Panel Regression and spatial heterogeneity
